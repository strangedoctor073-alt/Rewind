# REWIND Chrome Extension ↶

This directory contains the unpacked Chrome Extension for **REWIND**. It delivers local-first recording, session indexing, timeline inspection, and scroll rewind without requiring external servers or manual file imports.

---

## Directory Structure

```text
extension/
├── manifest.json       # Manifest V3 extension configuration
├── background.js       # Service worker (session manager & storage engine)
├── content.js          # In-page event listener & scroll restorer
├── popup.html          # Extension toolbar popup interface
├── popup.css           # Glassmorphism dark styling for popup
├── popup.js            # Real-time state polling & recording triggers
├── timeline.html       # Built Timeline dashboard (compiled from extension-src/)
└── assets/             # Bundled React application chunks
```

> [!NOTE]
> `background.js`, `content.js`, and `popup.*` are plain JavaScript loaded directly by Chrome.
> `timeline.html` and its bundles under `assets/` are generated by running `npm run build:extension` from the repository root.

---

## Installation & Setup

1. **Build the extension timeline**:
   ```bash
   npm run build:extension
   ```
2. Open Chrome (or any Chromium browser: Brave, Edge, Arc) and go to:
   ```text
   chrome://extensions
   ```
3. Enable the **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** in the top-left toolbar.
5. Select this `extension/` directory.
6. Pin **REWIND** to your browser toolbar for quick access.

---

## Usage Workflow

1. Navigate to any standard website (`http://` or `https://`).
2. Click the REWIND extension icon in your browser toolbar.
3. Click **Start recording** (the status indicator pulses red and the live duration timer begins).
4. Interact with the website normally: click buttons, type in search or forms, and scroll down the page.
5. Open the REWIND popup again and click **Stop recording**.
6. Click **Timeline / History** to open the split-pane dashboard:
   - Search across historical recordings with `/`.
   - Filter events by type: `Clicks`, `Inputs`, `Scrolls`.
   - Use <kbd>j</kbd>/<kbd>k</kbd> or <kbd>↑</kbd>/<kbd>↓</kbd> to navigate through events.
   - Click **Rewind to this moment** (or press <kbd>Enter</kbd>) to refocus the target tab and restore the exact scroll depth.

## Permissions Breakdown

REWIND adheres to the principle of least privilege:

| Permission | Purpose |
| :--- | :--- |
| `activeTab` | Grants temporary execution permission strictly when you click the extension popup on an active tab. |
| `scripting` | Allows injecting `content.js` to listen for clicks, typing, and scroll events during an active recording session. |
| `storage` | Stores recording summaries and event blobs locally in `chrome.storage.local`. |
| `tabs` | Resolves target URLs when rewinding so REWIND can focus an existing open tab instead of duplicating it. |

> [!IMPORTANT]
> REWIND deliberately does **not** request broad `<all_urls>` host permissions. It only captures events on tabs where you explicitly clicked "Start recording".
